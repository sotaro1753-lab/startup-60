# STARTUP 60

顔出しなし・日本語のスタートアップ解説ショート動画を制作するRemotionプロジェクト。

## 動かし方

Node.js 20以上とnpmを用意して以下を実行。

```bash
npm install
npm run preview
npm run render
```

プレビューはブラウザで開き、レンダリング後は `out/startup-60.mp4` に保存します。ブラウザやOSのフォント環境によって日本語の見え方が異なるので確認してください。

## 初回エピソード

「赤字でもなぜ数億円の資金調達ができるのか？」。55秒・縦型1080×1920・30fps。図解テキストのアニメーションを実装しています。

**現状:** 音声合成、BGM、音声同期、外部ソースからの自動原稿生成は未実装です。現在の出力は無音の映像です。動画レンダリング自体もこの変更では実行確認していません。最初にRemotion Studioで表示・日本語の文字切れを確認してください。
